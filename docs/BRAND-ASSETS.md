# Brand assets

The logo mark, favicon set and social preview image in this repository are **interim artwork**
made for the first build. They are deliberately simple so they can be replaced without touching
any layout or component logic. This file lists every brand asset, where it lives and what the
replacement must be.

## Inventory

| Asset                       | File                          | Format and size                                                            | Used by                       |
| --------------------------- | ----------------------------- | -------------------------------------------------------------------------- | ----------------------------- |
| Logo mark + wordmark        | `src/components/Logo.astro`   | Inline SVG (`viewBox 0 0 32 32`) + live text                               | Header, footer                |
| Favicon (modern browsers)   | `public/favicon.svg`          | SVG, square, legible at 16 px                                              | All pages                     |
| Favicon (legacy)            | `public/favicon.ico`          | ICO containing 16×16 and 32×32 PNGs                                        | All pages                     |
| Apple touch icon            | `public/apple-touch-icon.png` | PNG 180×180, opaque, no rounded corners (iOS applies its own)              | iOS home screen, JSON-LD logo |
| App icon                    | `public/icon-512.png`         | PNG 512×512, opaque                                                        | Web app manifest              |
| Social preview (Open Graph) | `public/og-image.png`         | PNG or JPEG 1200×630, under ~1 MB, key content inside the central 1000×520 | Link previews on every page   |
| Background texture          | `src/assets/grain.png`        | Generated by `scripts/generate-grain.mjs`                                  | Page background               |

The hero's network sphere is not an image: it is drawn in code by `src/scripts/network-core.ts`,
with colours taken from `src/styles/tokens.css`.

## Replacing the logo

1. Replace the `<svg class="logo__mark">…</svg>` in `src/components/Logo.astro` with the final
   mark. Keep `aria-hidden="true"` and `focusable="false"` — the accessible name comes from the
   link around it.
2. Prefer `currentColor` for strokes and fills so the mark inherits the surrounding text colour.
   Accent parts may use `var(--c-cyan)` or `var(--c-blue-bright)`.
3. If the final logo includes its own wordmark, remove the `.logo__type` block and keep an
   equivalent visually hidden label in the header link (it already has `aria-label`).
4. Do not embed raster images or remote URLs in the SVG: the Content Security Policy only allows
   same-origin images, and inline SVG must stay free of scripts and event attributes.

## Replacing the favicon and app icons

1. Overwrite `public/favicon.svg` with the final mark on a solid `#050814` (or brand) background.
2. Regenerate `favicon.ico`, `apple-touch-icon.png` and `icon-512.png` from the same artwork
   (any image editor or `rsvg-convert`/ImageMagick). Keep the file names and sizes above.
3. If the brand colour changes, update `themeColor` in `src/config/site.ts`.

## Replacing the social preview

1. Export a 1200×630 image to `public/og-image.png`. If you switch to JPEG, rename it and update
   the path in `src/components/SEO.astro`.
2. Update the `og:image:alt` text in `src/components/SEO.astro` to describe the new image.
3. Check the result with a link-preview debugger after deployment (platforms cache previews).

## Colour and type

The palette, type scale and motion values live in `src/styles/tokens.css`. The current values are
taken from the supplied concept boards (Deep Space `#050814`, Navy `#0B1E3A`, APOLLO Blue
`#1B4DFF`, Cyan `#00E0FF`). Text tokens are annotated with measured contrast ratios; recheck them
if any colour changes.
